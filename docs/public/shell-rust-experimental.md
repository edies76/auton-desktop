# Shell Rust experimental de Auton

La rama experimental `feat/codex/auton-gpui` abre proyectos locales en una ventana GPUI escrita en Rust y conecta el chat al runtime Auton existente. El agente conserva sus proveedores, herramientas y workers; la ventana muestra el plan y la evidencia que el agente registra.

Esta rama aún no reemplaza el cliente Electron como distribución estable. No se ha medido su rendimiento frente a Electron ni se ha probado una corrida visual con proveedor. GPUI 0.2.2 documenta macOS/Linux; Windows todavía no está soportado por esta propuesta.
